# Mental Cogs

Mental Cogs is concept art for an electronic dance music (EDM) project. The
current visual is a black-and-white side-profile helmet with a cog behind it,
inspired by the idea of a mind as a machine in motion.

The helmet artwork is an SVG at [`public/helmet-gear.svg`](./public/helmet-gear.svg).
The cog and side hinge have independent, continuous rotations to explore the
project's visual direction. This is an early concept, not a finished identity
or production-ready animation.

## Run locally

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — start the local development server
- `npm run lint` — run ESLint
- `npm run build` — create a production build
- `npm run start` — serve the production build
